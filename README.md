# Compiladores

**Descripción:**
Este repositorio contiene ejercicios prácticos y ejemplos relacionados con la construcción de compiladores, análisis léxico 
y validación de cadenas. Los ejercicios están implementados en Python y utilizan herramientas como PLY (Python Lex-Yacc).
